1. CZYM JEST BACKEND

To, czego użytkownik nie widzi

Aplikacja w przeglądarce i aplikacja na telefonie wyglądają inaczej, ale rozmawiają z tym samym serwerem. Serwer przyjmuje żądanie, sprawdza reguły biznesowe, czyta i zapisuje dane w bazie, a potem odsyła odpowiedź w JSON. Tę środkową część budujecie na laboratoriach.

Relacyjna baza danych

Dane w tabelach powiązanych kluczami obcymi: klient ma wiele rezerwacji, rezerwacja dotyczy jednej oferty. Na zajęciach H2: baza wbudowana w aplikację, nic nie trzeba instalować.

JPA i Hibernate

Klasy Javy oznaczone @Entity są mapowane na tabele. Zamiast pisać SQL ręcznie, piszecie repozytoria Spring Data, a Hibernate tłumaczy je na zapytania.

REST API

Zasoby pod adresami (/api/offers) i metody HTTP: GET czyta, POST tworzy, PUT/PATCH zmienia, DELETE usuwa. Odpowiedź to JSON i kod statusu (200, 201, 400, 404).

  • Zespół 3 osoby
